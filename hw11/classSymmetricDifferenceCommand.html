Подробное описание

Команда SYMMETRIC_DIFFERENCE для получения симметрической разности

Возвращает записи, присутствующие только в одной из таблиц (A или B) Формат команды: SYMMETRIC_DIFFERENCE

Возвращает
Результат в формате CSV: id,значение_из_A,значение_из_B Для записей только из A: значение_из_B пустое Для записей только из B: значение_из_A пустое

Отправляет серверу команду SYMMETRIC_DIFFERENCE и выводит результат симметрической разности данных из таблиц A и B.

Результат содержит строки, присутствующие только в одной из таблиц (либо в A, либо в B), отсортированные по id.
