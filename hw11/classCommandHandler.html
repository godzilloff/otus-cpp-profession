Подробное описание

Обработчик команд для сервера операций над множествами

Класс отвечает за обработку входящих команд от клиента. Использует фабрику команд для создания соответствующих объектов команд и выполнения их бизнес-логики.

◆ handle_command()

std::string CommandHandler::handle_command ( const std::string &  command_line)

Обрабатывает команду, полученную от клиента

Аргументы
command_lineСтрока с командой от клиента
Возвращает
Строка с результатом выполнения команды или сообщением об ошибке
  • Создает команду через фабрику команд
  • Выполняет команду и возвращает результат
  • В случае исключения возвращает сообщение об ошибке с префиксом "ERR"

Примеры возвращаемых значений:

  • "OK" - команда выполнена успешно
  • "ERR duplicate 0" - ошибка дублирования ID
  • "ERR unknown command" - неизвестная команда
Исключения
Можетпробрасывать исключения из фабрики команд или выполнения команд
