Подробное описание

Исполнитель команд для взаимодействия с сервером операций над множествами

Класс отвечает за выполнение команд через сетевое соединение с сервером. Реализует паттерн "Команда" для инкапсуляции запросов к серверу. Поддерживает как одиночное выполнение команд, так и пакетное выполнение.

Конструктор исполнителя команд

Аргументы
client_factoryФабрика для создания клиентов сетевого соединения

Принимает фабричную функцию, которая будет создавать новые экземпляры NetworkClient для каждого выполнения команды, обеспечивая изоляцию соединений.

Аргументы
client_factoryФабрика для создания клиентов подключения к серверу

Инициализирует исполнитель команд с переданной фабрикой клиентов. Фабрика будет использоваться для создания новых подключений к серверу при выполнении каждой команды.

Выполняет одну команду

Возвращает
true если команда выполнена успешно, false в случае ошибки

Создает новое сетевое соединение, выполняет команду и закрывает соединение. Автоматически обрабатывает ошибки соединения и выполнения команды.

Аргументы
commandУказатель на команду для выполнения
Возвращает
true если команда выполнена успешно, false в случае ошибки

Метод создает новое подключение к серверу, выполняет команду и закрывает соединение. Такой подход обеспечивает изоляцию команд и устойчивость к разрывам соединения.

Заметки
  • Создается новое подключение для каждой команды
  • Соединение автоматически закрывается после выполнения команды
  • Ошибки подключения и выполнения команды обрабатываются корректно
Пример использования:
auto executor = CommandExecutor(client_factory);
auto command = std::make_unique<InsertCommand>("A", 1, "test");
bool success = executor.execute_command(std::move(command));

◆ execute_commands()

void CommandExecutor::execute_commands ( const std::vector< std::unique_ptr< ICommand > > &  commands)

Выполняет набор команд последовательно

Аргументы
commandsВектор команд для выполнения

Выполняет команды в порядке их следования в векторе. Каждая команда выполняется в отдельном сетевом соединении. Продолжает выполнение даже при ошибках в отдельных командах.

Аргументы
commandsВектор команд для выполнения

Метод выполняет переданные команды одна за другой. Каждая команда выполняется в отдельном подключении к серверу. При ошибке выполнения одной команды выполнение продолжается со следующей командой в векторе.

Заметки
  • Команды выполняются в порядке их следования в векторе
  • Ошибка выполнения одной команды не прерывает выполнение остальных
  • Для каждой команды создается отдельное подключение к серверу
Пример использования:
std::vector<std::unique_ptr<ICommand>> commands;
commands.push_back(std::make_unique<InsertCommand>("A", 1, "test1"));
commands.push_back(std::make_unique<InsertCommand>("A", 2, "test2"));
executor.execute_commands(commands);
Предупреждения
Вектор команд передается по константной ссылке, но для выполнения команды требуется перемещение владения. Используется const_cast для обхода этого ограничения, что безопасно в данном контексте, так как вектор не изменяется.
