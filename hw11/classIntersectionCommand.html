Подробное описание

Команда INTERSECTION для получения пересечения множеств

Возвращает записи, присутствующие в обеих таблицах A и B с одинаковыми ID Формат команды: INTERSECTION

Возвращает
Результат в формате CSV: id,значение_из_A,значение_из_B

Отправляет серверу команду INTERSECTION и выводит результат пересечения данных из таблиц A и B по полю id.

Результат содержит строки, присутствующие в обеих таблицах с одинаковым id, с именами из обеих таблиц.
