Обрабатывает команду от клиента

Обрабатывает команду от клиента

Аргументы
command_lineСтрока с командой от клиента
Возвращает
Результат выполнения команды в виде строки
  • Парсит команду и создает соответствующий объект команды через фабрику
  • Выполняет команду и возвращает результат
  • В случае ошибки возвращает строку с префиксом "ERR"
Заметки
Форматы команд:
  • INSERT table id name
  • TRUNCATE table
  • INTERSECTION
  • SYMMETRIC_DIFFERENCE

handle_command("INSERT A 0 lean") -> "OK" handle_command("INTERSECTION") -> "3,violation,proposal\n4,quality,example\n5,precision,lake\nOK"
