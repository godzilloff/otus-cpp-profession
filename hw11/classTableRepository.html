Подробное описание

Реализация репозитория для работы с таблицами базы данных

Класс предоставляет методы для выполнения операций CRUD и операций над множествами для таблиц A и B.

Выполнение операции симметрической разности таблиц A и B.

Возвращает
Вектор строк результата симметрической разности

Возвращает записи, которые присутствуют только в одной из таблиц. Для записей из таблицы A поле column_b будет пустым, для таблицы B - column_a. Результат сортируется по возрастанию ID.

Заметки
В SQLite FULL OUTER JOIN эмулируется через комбинацию LEFT и RIGHT JOIN
