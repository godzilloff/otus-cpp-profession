Подробное описание

Основной класс сервера для обработки операций над множествами

Класс реализует асинхронный TCP-сервер, который принимает подключения клиентов и обрабатывает команды для операций над множествами (пересечение, симметрическая разность). Использует Boost.Asio для асинхронных сетевых операций.
