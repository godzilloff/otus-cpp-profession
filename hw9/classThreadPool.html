Detailed Description

Пул потоков для асинхронного выполнения задач

Обеспечивает выполнение задач в фиксированном количестве рабочих потоков. Задачи ставятся в очередь и выполняются в порядке поступления.

Note
Потокобезопасен - все операции защищены внутренними мьютексами
Автоматически управляет временем жизни рабочих потоков

Создает указанное количество рабочих потоков, которые начинают ожидать задачи в очереди. Каждый поток работает в бесконечном цикле, извлекая и выполняя задачи из очереди.

Note
Потоки создаются сразу при построении объекта
Имя пула используется только для отладочного вывода

Деструктор пула потоков

Автоматически останавливает все рабочие потоки и дожидается их завершения. Если в очереди остались невыполненные задачи, они будут проигнорированы.

Note
Вызывает shutdown() для корректного завершения работы

Автоматически вызывает shutdown() для корректного завершения всех рабочих потоков. Гарантирует освобождение всех ресурсов.

Warning
Не должен вызываться при наличии активных ссылок на объект

◆ shutdown()

void ThreadPool::shutdown ( )

Принудительная остановка всех потоков пула

Устанавливает флаг остановки, уведомляет все потоки и дожидается их завершения. Гарантирует, что все запущенные задачи будут завершены перед возвратом управления.

Warning
После вызова shutdown() добавление новых задач невозможно
// Пример корректного завершения
pool.shutdown();
// pool.enqueue_task(...); // ОШИБКА: пул уже остановлен

Устанавливает флаг остановки, уведомляет все ожидающие потоки и дожидается их завершения через join(). Гарантирует, что все потоки будут корректно остановлены перед возвратом управления.

Note
После вызова shutdown() добавление новых задач невозможно
Метод является идемпотентным - повторные вызовы безопасны
