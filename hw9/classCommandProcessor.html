Detailed Description

Основной обработчик команд с многопоточной архитектурой

Накопливает команды, формирует пакеты согласно заданному размеру и динамическим блокам, распределяет вывод между потоками консоли и файловыми потоками.

Note
Использует 3 фоновых потока: 1 для консоли и 2 для файлов
Поддерживает динамические блоки команд с помощью фигурных скобок
Обеспечивает потокобезопасность всех операций

void CommandProcessor::process_command ( std::string_view  command)

Обрабатывает очередную команду

Parameters
commandКоманда для обработки в виде string_view
Note
Поддерживает специальные команды "{" и "}" для динамических блоков
Автоматически завершает блок при достижении bulk_size (вне динамических блоков)
Потокобезопасна - может вызываться из любого потока
// Пример обработки команд
processor.process_command("cmd1");
processor.process_command("{"); // Начало динамического блока
processor.process_command("cmd2");
processor.process_command("}"); // Конец динамического блока
Parameters
commandКоманда для обработки в виде string_view

Обрабатывает команды согласно следующим правилам:

  • "{" - начинает динамический блок (увеличивает глубину вложенности)
  • "}" - завершает динамический блок (уменьшает глубину вложенности)
  • Обычные команды добавляются в текущий блок

Автоматически завершает блок при:

  • Достижении размера bulk_size (вне динамических блоков)
  • Завершении динамического блока (глубина вложенности становится 0)
  • Начале нового динамического блока
Note
Фиксирует время первой команды в блоке для генерации имени файла
Игнорирует лишние закрывающие скобки (глубина не становится отрицательной)

◆ shutdown()

void CommandProcessor::shutdown ( )

Принудительная остановка всех фоновых потоков

Останавливает потоки вывода в консоль и файлы, дожидается их завершения. После вызова обработчик не может использоваться для обработки команд.

Warning
Последующие вызовы process_command() после shutdown() не определены

Последовательно останавливает пулы потоков для консоли и файлов. После вызова обработчик не может использоваться для обработки команд.

Note
Безопасен для повторного вызова
Останавливает потоки в порядке: log, затем file
