# Bayan / Duplicate File Finder

Утилита для поиска дубликатов файлов по содержимому с использованием алгоритмов хэширования. Программа анализирует файлы блоками и находит идентичные файлы, даже если они имеют разные имена или находятся в разных директориях.

## Сборка

```bash
mkdir build
cd build
cmake ..
make
```

## Использование

```bash
./bayan [OPTIONS]
```

### Обязательные параметры

- `-d, --directories` - Директории для поиска (можно указать несколько)

### Опциональные параметры

- `-h, --help` - Показать справку по использованию
- `-e, --exclude` - Директории для исключения из поиска (можно указать несколько)
- `-l, --level` - Уровень сканирования (`-1` - без ограничений, `0` - только указанная директория)
- `-m, --min-size` - Минимальный размер файла в байтах (по умолчанию: 1)
- `--mask` - Маски файлов для фильтрации (например, `*.txt`, `*.jpg`)
- `-b, --block-size` - Размер блока для чтения файлов в байтах (по умолчанию: 4096)
- `-a, --algorithm` - Алгоритм хэширования (`crc32` или `md5`, по умолчанию: `crc32`)

## Примеры использования

### Поиск всех дубликатов в текущей директории
```bash
./bayan -d .
```

### Поиск дубликатов изображений в нескольких директориях
```bash
./bayan -d ~/Pictures -d ~/Downloads --mask "*.jpg" --mask "*.png" -m 1024
```

### Поиск с исключением определенных директорий и ограничением уровня
```bash
./bayan -d /data -e /data/temp -e /data/backups -l 2
```

### Поиск с использованием MD5 и другого размера блока
```bash
./bayan -d /storage --algorithm md5 --block-size 8192
```

### Поиск только больших файлов определенного типа
```bash
./bayan -d /archive --mask "*.pdf" --min-size 1048576
```

## Формат вывода

Результаты выводятся в стандартный вывод в следующем формате:
```
/path/to/first/duplicate/file1.txt
/path/to/second/duplicate/file2.txt
/path/to/third/duplicate/file3.txt

/path/to/another/group/file4.jpg
/path/to/another/group/file5.jpg
```

Каждая группа дубликатов разделяется пустой строкой. Файлы в пределах одной группы имеют идентичное содержимое.

## Особенности реализации

- **Бережное обращение с диском**: Файлы читаются только при необходимости
- **Ленивое вычисление хэшей**: Хэши вычисляются только когда файлы потенциально дублируются
- **Memory-mapped files**: Используется для эффективного чтения больших файлов
- **Двухэтапная оптимизация**: Сначала группировка по размеру, затем детальное сравнение

## Поддерживаемые алгоритмы хэширования

- **CRC32**: Быстрый алгоритм контрольных сумм
- **MD5**: Алгоритм хэширования (используется boost::hash для совместимости)

## Требования

- C++17 compatible compiler
- Boost Libraries (filesystem, program_options, iostreams, system)
- CMake 3.12+
