Подробное описание

Класс простого TCP-клиента для тестирования сервера

Обеспечивает подключение к серверу, интерактивный ввод команд и корректное завершение соединения. Использует синхронные операции Boost.ASIO для простоты реализации.

Запускает клиентский цикл работы

Возвращает
true если работа завершена успешно, false в случае ошибки

Выполняет последовательно:

  1. Разрешение доменного имени и порта
  2. Подключение к серверу
  3. Интерактивный ввод команд от пользователя
  4. Корректное закрытие соединения
Предупреждения
Метод блокирующий - управление вернется только после завершения работы
// Пример использования
SimpleClient client("localhost", "9000");
bool success = client.run();

Definition main.cpp:23

Разрешение хоста и порта в список endpoint'ов

Преобразует текстовые представления хоста и порта в список сетевых endpoint'ов для подключения.

Подключение к серверу

Выполняет попытку подключения ко всем endpoint'ам из списка до первого успешного подключения.

Цикл интерактивного ввода команд

Читает команды из стандартного ввода и отправляет их на сервер. Пустая строка или Ctrl+D завершают работу клиента.

Отправка данных на сервер

Синхронно записывает данные в сокет. Гарантирует, что все данные будут отправлены или возникнет исключение.

Корректное закрытие соединения

Выполняет graceful shutdown сокета для уведомления сервера о завершении передачи данных, затем закрывает сокет.
