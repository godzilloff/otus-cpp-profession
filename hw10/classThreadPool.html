Подробное описание

Класс пула потоков для асинхронного выполнения задач

Обеспечивает выполнение задач в фиксированном количестве рабочих потоков. Задачи ставятся в очередь и выполняются в порядке поступления. Пул автоматически управляет временем жизни рабочих потоков и обеспечивает потокобезопасность операций.

Основной цикл выполнения задач рабочим потоком

Каждый рабочий поток выполняет следующий алгоритм:

  1. Ожидает появления задачи в очереди или сигнала остановки
  2. Извлекает задачу из очереди (если доступна)
  3. Выполняет задачу вне критической секции
  4. Повторяет цикл до получения сигнала остановки
Заметки
Условная переменная обеспечивает эффективное ожидание без активного опроса очереди.

Ожидание условия для пробуждения потока

Поток блокируется до выполнения одного из условий:

  • Установлен флаг остановки (stop_ == true)
  • В очереди появилась новая задача (!tasks_.empty())
Заметки
Использование предиката предотвращает ложные пробуждения

Выполнение задачи

Задача выполняется вне критической секции, что позволяет другим потокам одновременно добавлять новые задачи в очередь.

Заметки
Исключения в задачах должны обрабатываться внутри самой задачи, так как пул потоков их не перехватывает.

◆ ~ThreadPool()

ThreadPool::~ThreadPool ( )

Деструктор пула потоков

Автоматически останавливает все рабочие потоки и дожидается их завершения. Если в очереди остались невыполненные задачи, они будут проигнорированы.

Заметки
Вызывает shutdown() для корректного завершения работы

Автоматически вызывает shutdown() для корректного завершения всех рабочих потоков. Гарантирует освобождение всех ресурсов.

Предупреждения
Не должен вызываться при наличии активных ссылок на объект
Заметки
Если деструктор вызывается без предварительного shutdown(), все невыполненные задачи в очереди будут потеряны.

◆ shutdown()

void ThreadPool::shutdown ( )

Принудительная остановка всех потоков пула

Устанавливает флаг остановки, уведомляет все потоки и дожидается их завершения. Гарантирует, что все запущенные задачи будут завершены перед возвратом управления.

Предупреждения
После вызова shutdown() добавление новых задач невозможно
// Пример корректного завершения
pool.shutdown();
// pool.enqueue_task(...); // ОШИБКА: пул уже остановлен

Выполняет следующие действия:

  1. Устанавливает атомарный флаг остановки
  2. Уведомляет все ожидающие потоки через condition_variable
  3. Дожидается завершения всех потоков через join()
Заметки
Гарантирует, что все запущенные задачи будут завершены, но задачи, оставшиеся в очереди, выполняться не будут.
Предупреждения
После вызова shutdown() добавление новых задач невозможно
Заметки
Метод является идемпотентным - повторные вызовы безопасны
// Пример использования
ThreadPool pool(4);
// ... добавление задач ...
pool.shutdown(); // Корректное завершение

Установка флага остановки

Атомарная установка флага ensures thread-safe операция без необходимости дополнительной синхронизации.

Уведомление всех ожидающих потоков

Пробуждает все потоки, ожидающие на condition_variable, чтобы они могли проверить флаг остановки и завершиться.

Ожидание завершения всех рабочих потоков

Для каждого потока в пуле:

  • Проверяет, можно ли присоединиться к потоку (joinable)
  • Вызывает join() для ожидания завершения
Заметки
join() гарантирует, что ресурсы потока будут освобождены и деструктор пула может безопасно завершиться.
