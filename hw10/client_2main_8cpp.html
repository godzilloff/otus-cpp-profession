Использование:
// Интерактивный режим
simple_client localhost 9000
// Передача команд через pipe
echo -e "cmd1\ncmd2\ncmd3" | simple_client 127.0.0.1 9000
// Чтение команд из файла
cat commands.txt | simple_client localhost 9000
Заметки
Для работы клиента должен быть запущен bulk_server на указанном порту
Предупреждения
Программа не возвращает управление до завершения работы пользователем или разрыва соединения с сервером.
