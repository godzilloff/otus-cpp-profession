Подробное описание

Обработчик команд с поддержкой паттерна Observer.

Класс отвечает за накопление, группировку и обработку команд в блоки согласно заданному размеру и правилам динамических блоков. Реализует интерфейс IObservable для уведомления зарегистрированных наблюдателей о сформированных блоках команд.

Заметки
Поддерживает два типа блоков:
  • Статические блоки: автоматически завершаются при достижении bulk_size
  • Динамические блоки: ограничиваются символами { и }, игнорируют bulk_size

void CommandProcessor::process_command ( std::string_view  command)

Обрабатывает очередную команду

Аргументы
commandКоманда для обработки в виде string_view

Обрабатывает команды согласно следующим правилам:

  • "{" - начинает динамический блок (увеличивает глубину вложенности)
  • "}" - завершает динамический блок (уменьшает глубину вложенности)
  • Обычные команды добавляются в текущий блок
Заметки
Автоматически завершает блок при:
  • Достижении размера bulk_size (вне динамических блоков)
  • Завершении динамического блока (глубина вложенности становится 0)
  • Начале нового динамического блока
Потокобезопасна - защищена внутренним мьютексом
Аргументы
commandКоманда для обработки в виде string_view

Анализирует тип команды и выполняет соответствующие действия:

  • "{" - начинает динамический блок, при необходимости завершая предыдущий
  • "}" - завершает динамический блок, обрабатывая команды если глубина = 0
  • Обычная команда - добавляется в буфер, проверяет условия завершения блока
Заметки
Фиксирует время первой команды в блоке для генерации временной метки
Автоматически завершает блок при достижении bulk_size вне динамических блоков
Поддерживает вложенность динамических блоков через счетчик block_depth_

◆ shutdown()

void CommandProcessor::shutdown ( )

Принудительная остановка всех фоновых потоков

Останавливает пул потоков для уведомления наблюдателей и дожидается их завершения. После вызова обработчик не может использоваться.

Предупреждения
Последующие вызовы process_command() после shutdown() не определены
Заметки
Метод является идемпотентным - повторные вызовы безопасны

Вызывает shutdown() пула потоков для уведомлений, что приводит к корректному завершению всех рабочих потоков. После вызова этого метода асинхронные уведомления наблюдателей прекращаются.

Заметки
Не влияет на уже отправленные уведомления - они будут обработаны
Безопасен для повторного вызова
