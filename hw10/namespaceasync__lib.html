◆ async_connect()

ASYNC_API handle_t async_lib::async_connect ( size_t  bulk_size)

Создает новый контекст для обработки команд

Аргументы
bulk_sizeРазмер блока команд для автоматической обработки
Возвращает
handle_t Указатель на созданный контекст обработчика

Инициализирует новый обработчик команд с заданным размером блока и автоматически подписывает на него стандартных наблюдателей (консоль и файл). Регистрирует обработчик в глобальной карте для последующего доступа.

Заметки
Каждый вызов создает независимый контекст обработки
Автоматически подписывает консольного и файлового наблюдателей
Предупреждения
Необходимо вызывать async_disconnect() для освобождения ресурсов
// Пример использования
handle_t h = async_connect(3); // Создает обработчик с блоком из 3 команд

◆ async_disconnect()

ASYNC_API void async_lib::async_disconnect ( handle_t  handle)

Завершает работу с контекстом обработчика и освобождает ресурсы

Завершает работу с контекстом обработчика

Аргументы
handleКонтекст обработчика для завершения

Выполняет принудительную обработку оставшихся команд, останавливает фоновые потоки, освобождает ресурсы и удаляет обработчик из глобальной карты.

Заметки
После вызова async_disconnect() handle становится невалидным
Выполняет flush_remaining() для обработки последних команд
Если handle невалиден, функция завершается без действий
Потокобезопасна - защищена мьютексом processors_mutex
// Пример: корректное завершение работы
async_disconnect(h); // Ресурсы освобождены, h больше не валиден
// async_receive(h, "new_cmd", 7); // ОШИБКА: h невалиден!

ASYNC_API void async_lib::async_receive ( handle_t  handle,
const char *  data,
size_t  data_size 
)

Передает команду на обработку в указанный контекст

Аргументы
handleКонтекст обработчика, полученный из async_connect()
dataУказатель на буфер с данными команды
data_sizeРазмер данных команды в байтах

Добавляет команду в буфер указанного обработчика. Когда накапливается достаточное количество команд (согласно размеру блока), они автоматически обрабатываются и отправляются наблюдателям для вывода.

Заметки
Если handle невалиден (уже удален или не существует), команда игнорируется
Потокобезопасна - защищена мьютексом processors_mutex
Использует string_view для эффективной работы со строковыми данными
// Пример: передача нескольких команд
async_receive(h, "start", 5);
async_receive(h, "process_data", 12);
async_receive(h, "end", 3);

Подписывает пользовательского наблюдателя на контекст

Подписывает наблюдателя на контекст

Аргументы
handleКонтекст обработчика
observer_handleУказатель на пользовательского наблюдателя

Добавляет пользовательского наблюдателя в список подписчиков указанного обработчика команд. После подписки наблюдатель будет получать уведомления о всех сформированных блоках команд данного обработчика.

Заметки
Наблюдатель должен реализовывать интерфейс IObserver
Память для пользовательского наблюдателя управляется вызывающим кодом
Если handle невалиден, функция завершается без действий
// Пример: подписка пользовательского наблюдателя
class MyObserver : public IObserver { ... };
MyObserver my_observer;
async_subscribe(h, &my_observer);

Отписывает пользовательского наблюдателя от контекста

Отписывает наблюдателя от контекста

Аргументы
handleКонтекст обработчика
observer_handleУказатель на пользовательского наблюдателя

Удаляет пользовательского наблюдателя из списка подписчиков указанного обработчика команд. После отписки наблюдатель больше не будет получать уведомления от данного обработчика.

Заметки
Если наблюдатель не был подписан, функция завершается без действий
Если handle невалиден, функция завершается без действий
// Пример: отписка пользовательского наблюдателя
async_unsubscribe(h, &my_observer);
